# SRS LIVESTREAM

### Connect • Stream • Share

A professional Android Live Streaming Social Media Platform.

## Main Features

- Real OTP Login & Registration
- User Profiles & Unique ID
- Host Verification
- Single Host Live Streaming
- Multi-Guest Live Streaming
- Real-Time Live Chat
- Private Messaging
- Follow & Followers
- Like & Comments
- Coin Recharge
- Virtual Gift System
- Animated Gifts
- Host Earnings
- Real Money Withdrawal
- bKash & Nagad Integration
- Wallet & Transaction History
- Notifications
- User & Host Rankings
- Admin Dashboard
- Bengali & English Language
- Security & Privacy

## Technology

- Kotlin
- Jetpack Compose
- Node.js
- PostgreSQL
- Agora / LiveKit
- Firebase
